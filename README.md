Compilador desenvolvido em C para a linguagem **SAL (Simple Academic Language)**, criado para a disciplina de Compiladores.

O projeto implementa:

- Análise Léxica
- Análise Sintática (ASDR)
- Tabela de Símbolos
- Controle de Escopos
- Geração de Logs
- Interface CLI
